Getting started

Find the pumps that run below their efficiency target. The trend shows every pump against the target; the ranking lists the pumps to inspect first.

Steps iEach step works on the visual next to it. Marking a pump in one visual highlights it in every visual on the page.

  1. Set the efficiency target in the settings card.
  2. Press Run Analysis.
  3. Mark pumps in the ranking to see their trends.
